Note for faculty

This is a self-contained teaching aid, not a substitute for ICAI study material. All scenarios are fictional and safe for classroom use — no real credentials, live attacks, or external services are involved. Suggested flow: Home → Phishing → Password → Social Engineering → Firewall → Encryption → Audit Log → Attack Lifecycle → Assessment (approx. 60–75 minutes for a full batch walkthrough).

Module 02

Password Strength Lab

Type a sample password below (never use a real one). See how length, character variety and dictionary patterns affect brute-force resistance — a core preventive control under logical access security.

Strength: — Est. crack time: —

Why this matters for ITT / IS audit

Password policy is one of the most commonly tested preventive controls in an IS audit — minimum length, complexity, history, expiry and lockout threshold. A weak password policy is frequently flagged as a control deficiency. Discuss: should this be a detective or preventive control? What compensating control (MFA) reduces reliance on password strength alone?
