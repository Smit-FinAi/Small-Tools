FAQ
How do I remove a watermark in a non-standard position?

Use the Live Patch tab. Hover over the image — the patch follows your cursor and shows a live preview of the removal. Resize using the sliders until it perfectly covers the watermark, then click to stamp it.

What alpha map size should I pick?

Try 96px first (default). If the result has halos or dark patches, try 48px. "Auto" selects based on image dimensions. You can also just resize the patch visually — the sliders are more important.

Are my images uploaded anywhere?

Never. Everything runs in your browser. No server, no uploads, no network calls — 100% private.

How do I install this as a PWA?

Host on GitHub Pages (HTTPS). Chrome on Windows/Android shows an "Install" button in the address bar. On iOS Safari, tap Share → Add to Home Screen.
