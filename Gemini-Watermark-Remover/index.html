FAQ
Does this work completely offline?

Yes — every asset is embedded inside this single HTML file. No internet connection is required after you download it. The watermark map images are baked in as base64 data.

Are my images uploaded anywhere?

Absolutely not. All processing happens 100% in your browser using the HTML5 Canvas API. Your images never leave your device.

What image sizes does it support?

Images larger than 1024×1024 pixels use the 96×96px watermark map with 64px margins. Smaller images use the 48×48px map with 32px margins. Both are handled automatically.

Why did the original tool fail with a canvas error?

The original version loaded watermark maps from separate PNG files. When opened via file:// protocol, browsers block canvas pixel access on externally-loaded images (canvas taint). This version embeds everything inline, solving that issue entirely.
